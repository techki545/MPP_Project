# 模型超时循证回退设计

## 目标

当 DeepSeek 或其他兼容模型在请求时限内没有返回结果时，网页仍必须展示两部分完整输出：可折叠的循证过程、带引用的综合回答，以及一张非空且可追溯的证据关系图。

## 设计

正常路径保持不变，继续使用模型抽取临床主张并生成综合回答。模型超时、拒绝或返回无效格式时，流水线从每个高优先级来源的题名、摘要或命中文本中选择一段原文，构造成方向为 `uncertain` 的提取式主张。主张不推断疗效、剂量或安全性，仅记录来源中实际出现的文本，并保留文献编号和块编号。

关系图将不确定主张以 `supplements` 关系连接到临床问题，含义限定为“该来源为问题补充了相关证据”，不表示支持治疗结论。回退回答按证据金字塔统计来源，展示时间范围、最高等级证据和可追溯摘录，并明确说明模型超时及语义判断边界。

为避免图形过密，确定性回退最多选取检索排序最靠前的 8 项来源；完整的 15 项来源仍保留在证据清单中。

## 验收标准

- 模型超时时 `claim_count` 大于 0。
- 关系图至少包含问题节点、提取式主张节点和连接边。
- 综合回答包含“证据概况”“关键证据摘录”“综合判断”并带有效 `[N]` 引用。
- 页面继续显示模型超时警告，不把确定性回退标成模型生成。
- 正常模型路径及现有安全校验不受影响。
